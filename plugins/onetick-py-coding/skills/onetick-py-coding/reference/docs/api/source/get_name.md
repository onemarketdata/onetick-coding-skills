# otp.Source.get_name

#### ``Source.get_name(remove_invalid_symbols=False)``

Returns source name.

* **Parameters:**
  **remove_invalid_symbols** (*bool*) – If True, all characters not supported in query names in .otq file will be replaced,
  because only alphanumeric, minus and underscore characters are supported in query names.
* **Return type:**
  `str` | None
